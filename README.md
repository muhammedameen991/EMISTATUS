# EMI STATUS — English Edition

A lightweight, deployment-ready financial-awareness website.

## Features
- 100% English UI/content
- Responsive premium dark design
- EMI calculator
- Affordability indicator
- Financial-awareness content
- SEO metadata
- Open Graph metadata
- robots.txt + sitemap.xml
- Basic security headers
- No backend
- Vercel-ready

## Deploy
Upload this folder to Vercel, or run:

    npm i -g vercel
    vercel

After deployment, replace `https://your-domain.vercel.app/` with your actual domain in:
- index.html
- robots.txt
- sitemap.xml
